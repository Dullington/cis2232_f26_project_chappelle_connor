# Project Title

Tennis Match Score & Statistics Tracker


# Project Base Color

Pumpkin Orange



# Description

This application tracks the score and statistics of a tennis match, including the details of the players, the date and time of the match that was played, points scored, sets, aces, faults, and the winner of the match.

# Fields

Name Data Type Description

id int Unique identifier for database table

firstName String Player first name

lastName String Player last name

dateOfBirth String Player date of birth

matchDate String Date the match was played

createdDateTime String Date and time the match was entered

winnerName String Name of the player who won the match

tournamentName String Name of the tournament

courtSurface String Type of court surface (hard, clay, grass, etc)

setsPlayed int Number of sets played in the match

player1SetsWon int Number of sets won by Player 1

player2SetsWon int Number of sets won by Player 2

player1Aces int Number of aces hit by Player 1

player2Aces int Number of aces hit by Player 1

player1DoubleFaults int Number of double faults by Player 1

player2DoubleFaults int Number of double faults by Player 2

player1FirstServe int First-serve percentage for Player 1

player2FirstServe int First-serve percentage for Player 2

player1BreakPointsWon int Number of break points won by Player 1

player2BreakPointsWon int Number of break points won by Player 2

player1TotalPointsWon int Total points won by Player 1

player2TotalPointsWon int Total points won by Player 2

# Calculation

The app will calculate the winner by measuring each player’s points won and lost.
